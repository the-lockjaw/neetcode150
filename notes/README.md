# Notes

Index of study notes. Solutions live in the numbered step folders at the repo root. Notes here are concepts only.

## Structure

- `mistakes_log.md`: running log of what I missed on each problem, linking to the relevant note
- `cpp/`: C++ language and STL notes
  - [hash_containers.md](cpp/hash_containers.md): map, unordered_map, set, unordered_set
- `arrays_and_hashing/`: per-problem notes for Step 1
  - [contains_duplicate.md](arrays_and_hashing/contains_duplicate.md): approach comparison, review takeaways, follow-ups
  - [valid_anagram.md](arrays_and_hashing/valid_anagram.md): why check lengths first, map vs array vs sort, follow-ups
- Future: `patterns/` for technique notes (two pointers, sliding window, ...) as they come up

## Conventions

- File names are `snake_case.md`, one concept per file.
- Every note starts with an "Origin" line linking back to the mistakes log entry that caused it.
- Every new note gets a line in this index and, if it came from a mistake, a row in the log.
